# Antigravity 2.0 桌面端 App 内置斜杠指令速查与辨析

本手册**仅面向 Google Antigravity 2.0 桌面端 App**，不包含终端 `agy` CLI 专属指令或 IDE 编辑器特性。当用户需要完整速查表、对比易混指令或询问桌面端操作替代路径时读取本文件。

---

## 一、4 组高频易混指令临界差异

### 1. 动手前规划：`/grill-me` vs `/plan`

| 对比维度 | `/grill-me` | `/plan` |
| --- | --- | --- |
| **适用起点** | 想法还在毛坯阶段，核心规则、输入输出、边界条件尚未敲定 | 要做什么已经明确，但改动文件较多、涉及公共接口或核心架构 |
| **触发行为** | 每次只问 1 个最关键的问题并置顶 `(Recommended)` 推荐选项，逐题消灭盲区 | 先只读调研代码库与依赖，生成可审阅的 `Implementation Plan` 产物，获批后再改代码 |
| **衔接方式** | 追问对齐后，可紧接 `/plan` 出具体施工方案 | 若 `/plan` 调研时发现核心业务规则缺失，应退回先跑 `/grill-me` |

### 2. 自治与多智能体（5 档对比）

| 指令 | 并发形态 | 最对症的任务画像 | 套餐要求 | 普通账号平替方案 |
| --- | --- | --- | --- | --- |
| `/goal` | 单智能体长闭环 | 目标与验收标准明确（如修通编译与测试），希望无人值守跑通 | 全部套餐 | 直接可用 |
| `/boost` | 三层推演多假设验证 | 单个极难啃的硬骨头：反复未修好的 Bug、并发死锁、复杂算法优化 | 付费计划 | 用 `/plan` 列出排查假设，逐一验证 |
| `/swarm` | 具名 Worker + Verifier 留言板协作 | 2～6 个独立模块并行开发且需要专人验收 | Google AI Pro / Ultra | 拆成独立阶段配合 `/goal` 顺序执行 |
| `/run-workflow` | 动态 Python 脚本调度批量子智能体 | 大批量**同质对象**需大模型语义理解（如批量审 15 个模块、批量补单测） | Google AI Pro / Ultra | 按每批 3～5 个对象挂载 `@文件` 分批处理 |
| `/teamwork` | 多角色长周期工程团队 | 数小时到数天的仓库级框架迁移、子系统重写 | 付费计划 | 先 `/grill-me` + `/plan` 拆里程碑，分会话推进 |

### 3. 定时任务：`/schedule` vs `/automation`

| 对比维度 | `/schedule` | `/automation` |
| --- | --- | --- |
| **生命周期** | 当前会话内的一次性倒计时（Timer）或绑定对话的周期 Cron | 独立后台常驻定时工作流（如每天早 9 点自动汇总），可脱离当前对话管理 |
| **管理入口** | 当前会话后台任务列表 | Antigravity App 左侧 **Automations** 面板 |
| **适用定位** | 临时等待（如 20 分钟后检查构建） | 长期固定周期的自动化任务（App 专属） |

### 4. 对话减负：`/btw` vs `/compact`

| 对比维度 | `/btw` | `/compact` |
| --- | --- | --- |
| **解决痛点** | 主线推进过程中顺便问个旁支问题，不想打断主线或污染历史 | 长对话聊了数十轮后上下文接近上限、响应变慢，仍需接着前文继续 |
| **实际效果** | 在只读旁支中快速回答，主线对话零污染 | 将冗长历史浓缩为高密度上下文摘要，释放大量窗口空间 |

## 二、Antigravity 2.0 App 全量 19 项内置斜杠指令目录

### 1. 需求与规划（2 项）
- `/grill-me`：单题追问访谈（每次 1 题附推荐项），把模糊想法打磨清晰
- `/plan`：只读调研后输出可审阅 `Implementation Plan` 方案，确认后再改代码

### 2. 自治与多智能体（5 项）
- `/goal`：单目标持续执行与自我纠错闭环，直到达成验收条件
- `/boost`：多假设深层推演与独立验证，专攻疑难故障与性能/算法瓶颈（付费计划）
- `/swarm`：在共享留言板上组织多个具名 Worker 与 Verifier 协同工作（Pro / Ultra）
- `/run-workflow`：编写并运行 Python `parallel()` / `pipeline()` 脚本并发处理批量同质语义任务（Pro / Ultra）
- `/teamwork`：长周期多角色协作团队，适合大型仓库重构与架构迁移（付费计划）

### 3. 旁支工具与可视化（4 项）
- `/btw`：顺便提出只读旁支问题，不污染主线历史
- `/compact`：压缩总结当前长对话，释放上下文空间
- `/browser`：调度内置 `browser` 子智能体操作真实网页、核验前端渲染与截图
- `/generative_ui`：生成内嵌或独立的交互式 HTML 图表、流程图与教学演示（App 专属）

### 4. 定时与常驻自动化（2 项）
- `/schedule`：在当前会话设定一次性倒计时或周期 Cron 提醒
- `/automation`：交互式设计常驻后台自动化任务，统一在左侧 Automations 面板管理（App 专属）

### 5. 规则沉淀、插件与官方文档（6 项）
- `/learn`：把对话中的人工纠正与偏好持久化保存为 Rules 或 Skills
- `/plugin`：管理、启用、停用或打包插件（Plugins）
- `/agy-customizations`：查阅官方定制体系规范（Rules / Skills / Plugins / Hooks / MCP）
- `/migrate-agent-settings`：将 Claude Code、Cursor、Codex 等外部 Agent 配置迁移为 Antigravity 插件
- `/migrate-workflows`：扫描旧版 Workflow 并自动升级为现代 `SKILL.md`
- `/antigravity-guide`：查询 Antigravity 2.0 App 官方文档与功能指南

## 三、`@` 上下文挂载高频模板

- **锁定修改范围**：
  ```text
  /plan 升级 @src/目标模块/ 支持新配置项，先只读调研并给出修改方案
  ```
- **喂终端报错持续修通**：
  ```text
  /goal 参考 @终端 的报错信息修复构建与单测，直到全部测试通过
  ```
- **批量按规范质检**：
  ```text
  /run-workflow 对照 @AGENTS.md 规范，并行审查 @目标目录/ 下所有子模块并汇总问题清单
  ```
- **跨会话接续上下文**：
  ```text
  /plan 延续 @历史会话 里敲定的接口结构，完成剩余模块实现
  ```

## 四、桌面端被问及 CLI 专属能力时的标准指路

- **“怎么敲指令撤回上一步 / 回滚更改？”**：Antigravity 2.0 App 聊天框没有 `/undo` 或 `/rewind` 指令；请直接点击聊天记录中对应消息旁的回退/重编辑入口，或在 **Files Changed / Review Changes** 面板中拒绝单文件改动。
- **“怎么敲指令分叉对话？”**：桌面端没有 `/branch` 或 `/fork` 指令；请新建一个对话窗口，在输入框键入 `@` 引用刚才的 `@历史会话`，即可基于原有结论继续探索另一方案。
- **“怎么敲指令切换思考档位或查额度？”**：桌面端没有 `/effort` 或 `/usage` 指令；请在输入框下方的模型选择器切换模型档位，或在左侧导航与插件面板查看配额信息。
